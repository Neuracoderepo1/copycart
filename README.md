# CopyCart

Cross-exchange trader discovery and risk intelligence. **Demo-data build:** every trader shown is a
synthetic fixture. No live exchange data, verified track records, trade execution, or copying exists
in this version.

## Run

```bash
npm install
npm start            # http://127.0.0.1:3000  (PORT / HOST override)
npm run check        # lint + typecheck + tests
npm run smoke        # starts the real server and makes real HTTP requests
npm run openapi      # writes docs/openapi.json from src/routes.js
npm run keygen       # prints a NEW API key and its SHA-256 hash
```

Node.js 22+. ES modules, JSDoc + strict `tsc`, no runtime dependencies.

## Layout

| Path               | Purpose                                                              |
| ------------------ | -------------------------------------------------------------------- |
| `src/scoring.js`   | Versioned, pure scoring engine (no I/O, no UI)                       |
| `src/adapters/`    | Normalized trader contract, demo fixture adapter, planned exchanges  |
| `src/data/`        | Synthetic fixtures and the query/sort/paginate store                 |
| `src/routes.js`    | Single route table used by the router, auth rules and OpenAPI export |
| `src/api.js`       | `/api/v1` handlers, validation, auth, rate limiting                  |
| `src/analytics.js` | Privacy-minimal event schema and safe outbound redirects             |
| `src/server.js`    | HTTP server, static files, security headers                          |
| `public/`          | Browser UI (plain ES modules, no framework)                          |

## Scoring (v0.1.0-provisional)

0-100 descriptive score of an observed record: risk-adjusted return 35%, drawdown 25%, consistency
20%, data reliability 20%. Weights are **provisional and unvalidated**; the score does not predict
profit. Fewer than 30 valid observations yields no score. Zero variance, invalid values, stale or
gappy data are handled explicitly and reported as flags. Flags are statistical prompts, not
accusations. See `GET /api/v1/methodology`.

## API (`/api/v1`)

`GET /health`, `/methodology`, `/exchanges`, `/traders`, `/traders/{id}`, `/traders/{id}/performance`,
`/traders/{id}/score`; `POST /events`; `GET /outbound/{exchangeId}`; `GET /analytics/summary` (key
required). Errors use `{ "error": { "code", "message" } }`.

Auth: optional `X-API-Key` raises the rate limit; an invalid key is always 401.
`COPYCART_REQUIRE_KEY=1` requires a key on every route except `/health`. Keys are generated by
`npm run keygen`; provisioning means adding the printed **hash** to `COPYCART_API_KEY_HASHES`
(comma-separated). Raw keys are never stored by the server.

## Environment

`PORT`, `HOST`, `COPYCART_API_KEY_HASHES`, `COPYCART_REQUIRE_KEY`, `TRUST_PROXY`, `RATE_LIMIT_ANON`
(default 60/min), `RATE_LIMIT_KEY` (default 600/min), `REFERRAL_URL_<EXCHANGE>` (https only, must be
on the exchange's own domain, otherwise the redirect is refused). Never commit `.env`.

## Referral analytics

Events: `profile_view`, `search`, `filter`, `compare`, `outbound_click`. No IPs, cookies, user agents
or search text are stored; UTM values are sanitised. Outbound clicks are click-only; **no conversion
is reported** until verified partner data exists. The event buffer is in memory and resets on restart.

## Exchange adapters

Binance, Bybit, OKX, Bitget, BingX and Deribit are registered as **planned** and return no data.
Before enabling any, verify and document: API access and authentication, rate limits, historical
coverage, and commercial redistribution terms. Nothing here has been verified.

## Not done / limits

No live data, no persistent database, no browser-automation test run, no deployment. Analytics are
in-memory. Scores are unvalidated against historical outcomes.
